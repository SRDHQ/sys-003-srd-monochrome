# SRD Monochrome — Obsidian theme

The vault's counterpart to the SWITCHBOARD console and EXCHANGE (D-086, D-089) and the
SRD Monochrome kitty theme (D-090).

- Black background, soft white text (`#e6e6e6`), white for emphasis.
- No hue. States are told apart by weight, reverse video, frames and symbols, as in the console.
- Text greys are the kitty theme's: `#bcbcbc`, `#8a8a8a`, `#767676` — 11.06, 6.08 and 4.62:1 on black (measured, WCAG formula).
- Control borders `#767676` (4.62:1); decorative rules `#3a3a3a` (the inactive kitty border).
- DOS double-line frames (`border: 3px double`) on modals, menus, callouts, code and tables.
- Active tab, selection, search hits, primary buttons and checked boxes in reverse video.
- Links are underlined (no colour to rely on); unresolved links use a dotted underline.
- Monospace interface; no CRT raster, no motion.

Select it in Settings → Appearance → Themes → SRD Monochrome (base colour scheme: Dark).
