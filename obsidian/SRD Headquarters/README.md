# SRD Headquarters — Obsidian Theme

A dark retro-futurist theme based on the SRD Headquarters visual language.

Palette:
- Void: #000d12
- Signal cyan: #17acbb
- Deep cyan: #036779
- Instrument amber: #d77a10
- Bright amber: #f59a18
- Warm bone: #d8cfaf

Install: copy this folder into `<your-vault>/.obsidian/themes/` (or run
`./install.sh obsidian <your-vault>` from the repository root), then select it in
Settings → Appearance → Themes.

The theme is intentionally restrained: the cyber/retro treatment is concentrated
in the palette, square geometry, subtle scanlines, instrument-like highlights,
code blocks, navigation states, and graph view rather than glowing every element.
